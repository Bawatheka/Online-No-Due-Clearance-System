Project Overview

The Online No Due Clearance System is a web-based project designed to simplify the process of checking and applying for student no due clearance.

This system provides a simple interface where students can check their no due status and submit their clearance application. It also includes a staff login section for managing the clearance process.

Objectives
To simplify the student no due clearance process.
To allow students to check their clearance status online.
To provide an online application form for no due clearance.
To reduce manual paperwork and time.
To provide an easy-to-use interface for students and staff.

How to Run the Project
Download or clone this repository.
Open the project folder.
Make sure index.html, style.css, and script.js are in the same folder.
Open index.html in any modern web browser.
The Online No Due Clearance System will be displayed.
Student Portal

The Student Portal allows students to:

Enter their Student ID.
Enter their Full Name.
Check their no due clearance status.
Apply for no due clearance.
Staff Login

The Staff Login section is designed for staff members to access and manage student no due clearance applications.
