Project Overview

Online No Due Clearance System is a web-based application designed to simplify the student no due clearance process. It allows students to check their no due clearance status, submit a no due application, and provides a staff login section for managing the clearance process.

How to Run the Project
Download or clone the repository.
Open the project folder.
Make sure index.html, style.css, and script.js are in the same folder.
Open index.html in a web browser.
Student Portal

The Student Portal allows students to:

Enter their Student ID.
Enter their Full Name.
Check their no due clearance status.
Apply for no due clearance.
Staff Login

The Staff Login section provides an interface for staff members to access and manage student no due clearance applications.

Project Purpose

This project was developed as an academic project to demonstrate the use of HTML, CSS, and JavaScript for developing a web-based Online No Due Clearance System.
